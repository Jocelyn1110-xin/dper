# dper

一个给算法竞赛选手用的"对拍"工具 —— 自动生成测试数据，比较两份代码的输出是否一致。

---

## 为什么需要它？

- 场景：写完一道题的代码，交上去 WA 了，但不知道哪组数据挂的
- 手动造数据太慢，而且容易漏边界情况
- 对拍的做法：写一份"慢但一定对"的暴力解法当参照，让程序自动造数据、自动比较
- 本项目的价值：不用再手写脚本，一条命令跑上千次，出错立刻停下并告诉你第几轮

---

## 编译

**方式一：一键编译**

```
build.bat
```

**方式二：手动用 g++**

```
g++ -std=c++20 -O2 -Wall -Wextra main.cpp runner.cpp parseCnt.cpp readAns.cpp -o dper.exe
```

**编译完可得到 `dper.exe`/ `gen.exe` / `std.exe` / `brute.exe`**

## 使用

**前提：两个被测程序都必须从标准输入读、往标准输出写。**

也就是说，你的程序在终端里能这样跑：

```
你的程序.exe < 输入数据.txt
```

如果你习惯用 `freopen`，请确认它读的是 stdin，而不是写死的文件名。

**命令格式**

```
dper.exe <参数1> <参数2> <参数3> <参数4> <参数5>
```

| 位置 | 是什么 | 例子 |
|---|---|---|
| 1 | 你的正解程序**路径** | `std.exe` |
| 2 | 待检测程序**路径** | `brute.exe` |
| 3 | 数据生成器**路径** | `gen.exe` |
| 4 | 中间数据文件名（随便起） | `data.txt` |
| 5 | 跑多少轮 | `1000` |

**例子**

```
> dper.exe std.exe brute.exe gen.exe data.txt 1000

1/1000 ... 437/1000 ... 438/1000 ...
===========================
MISMATCH at round 439
std   = 2149
brute = 2150
===========================
```
**例子说明**
- 看到这个，说明第 439 轮发现了不一致，两个答案不一样。

**其他说明**
- data.txt 里保留的就是那组出错的数据 —— 这是"立刻停止"的设计目的。

---

## 退出码含义

| 退出码 | 含义 |
|---|---|
| `0` | 全部通过 |
| `1` | 出错（参数错误 / 文件打不开 / 某个程序崩溃） |
| `2` | **发现了不一致** |

**所以在脚本里可以这样用 `dper.exe ... && echo PASS || echo FAIL`**

---

## 已知限制
- 只比较"词的序列"，不处理浮点误差（1.0 和 1.00 会判不同）；
- 没有超时检测（如果某个程序死循环，dper 会一直卡住）；
- 程序路径需要你自己先编译好（dper 不负责编译）；
- 目前只在 Windows 上测过。
